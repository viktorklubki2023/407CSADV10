## Короткий опис проєкту

Проєкт містить конфігурацію AI-агента для VS Code Copilot, який створює
кросплатформний Rust/Cargo Hello World проєкт, налаштовує збірку, тести та
GitHub Actions CI для Windows, Linux і macOS.

## Запуск агента

1. Відкрити папку репозиторію у VS Code.
2. Відкрити Copilot Chat.
3. Вибрати агента `build-engineer`.
4. Виконати команду `/init`.

## Commands

- `/git-init` — перевірити Git-репозиторій і налаштувати `.gitignore`.
- `/create-project` — створити базову структуру Rust/Cargo проєкту.
- `/create-build` — налаштувати Cargo, тести та скрипти збірки.
- `/create-actions` — створити GitHub Actions workflow.
- `/check` — виконати повну перевірку проєкту в режимі лише читання.
- `/init` — послідовно виконати всі команди та фінальну перевірку.
